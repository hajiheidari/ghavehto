# Flutter development foundation

`lib/main.dart` requests the shared bootstrap from one Flutter consumer codebase for iOS/Android. Validated bootstrap/access DTOs are generated from Nest OpenAPI. `android/` and `ios/` are checked-in source from official Flutter 3.47.5 templates, downloaded from CI artifact 12578868322 (run 40141600010 / code 35bc23a). ZIP SHA256: `acb01b8dde7a79020e89916bf5d95e750b49d498062d59925d52d53e162f46aa`. Machine paths, caches, Pods and build output are excluded using the native template ignore rules.

Pinned cloud CI has executed Flutter analyze/widget/API tests, Android debug and iOS simulator debug builds; exact tested commits/runs are in TESTING.md. This local host lacks Flutter/Android SDK/macOS. CI now builds the checked-in platform projects without running `flutter create`. Native app IDs `com.ghahvehto.ghahvehto` and generated launcher icons are provisional development assets; store signatures, final brand icons and actual device testing remain release work. Android release signing is deliberately unconfigured.

Use the pinned Flutter SDK and existing native projects; do not regenerate templates as an unreviewed upgrade. Android emulator normally needs host 10.0.2.2 and iOS simulator loopback; current API intentionally binds desktop loopback. Physical-device testing requires an explicitly configured reachable development server and narrowly scoped transport security settings. Never add global cleartext exceptions to release apps. Use HTTPS for actual deployment. Secure platform token persistence and genuine initial login UI will be integrated with the approved provider flow; no tokens are persisted by this foundation screen.

Android's HTTP exception exists only in the debug manifest. The main manifest grants Internet and RTL support; native display names are Persian. No public login or demo token is supplied. Existing template XCTest source is scaffolding and is not claimed as executed native behavior coverage. Use `flutter build apk --debug --dart-define=API_BASE_URL=http://10.0.2.2:4101` or macOS `flutter build ios --simulator --debug --no-codesign --dart-define=API_BASE_URL=http://127.0.0.1:4101` for local development checks.
