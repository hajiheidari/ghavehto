# Milestone plan

1. M0: evidence-backed feasibility, architecture/schema/security/agent/cost plans and executable connectivity probe. Exit: docs reviewed, tests recorded, unresolved decisions explicit.
2. M1: install approved toolchains; choose and lock supported Nest/Next/Flutter versions; generate native projects and clients; PostgreSQL migrations; authentication/tenant foundation; CI and RTL design system. Exit requires every platform build and database/auth tests. Depends on publisher feasibility research, not account purchases.
3. M2: directory search/provenance and progressive claim/verification; local permitted fixtures; maps adapter feasibility; real café scope guards. Exit includes SSR and correction workflows, migration upgrades and cross-tenant API/e2e checks.
4. M3: program versioning, secure QR transaction, redemption stock, independent journals and referral risk. Exit includes concurrent database invariants and recovery from repeated requests.
5. M4: experiences, eligibility/founders windows, first-visit budgets, printable tracked café QR and analytics. Exit includes expiry, negative stock and attribution distinction tests.
6. M5: deterministic worker framework, four agents, approvals and shared CMS. Exit includes pause/retry/lease recovery, approval tamper and disabled-provider tests.
7. M6: security review, physical-device Iranian connectivity, performance, privacy/deletion, backup restoration, store assets and approved deployment plan. Releases/submissions/marketing require founder authorization separately.

No date estimates before toolchain and distribution blockers are resolved. Keep tasks small enough for one reviewable commit with executed checks. Do not mark milestones complete from scaffold presence.
